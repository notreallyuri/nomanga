# Screenshots

Images referenced by the docs. Capture at a window size around 1280×800 so text
stays legible when scaled down, and take light and dark from the same screen if
you add both.

| File | Referenced by | What it should show |
|---|---|---|
| `icon.png` | `README.md` | The app icon, 96px or larger. Copy from `client/src-tauri/icons/128x128@2x.png`. |
| `library.png` | `README.md` | The library with a few categories and covers — the headline shot. |
| `reader.png` | `README.md` | A chapter open, ideally webtoon or double-page so the layout reads as deliberate. |
| `extensions.png` | `docs/extensions.md` | Settings → Extensions with a repository added and something installed. |

Mind what is on screen: these end up in a public repository, and the library and
browse screens show whatever is actually in yours.
